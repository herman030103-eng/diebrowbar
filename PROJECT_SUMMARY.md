# AI Email Agent - Полная Реализация Проекта

## 🎯 Что Создано

Полнофункциональный AI Email Agent - система автоматизации управления электронной почтой с искусственным интеллектом.

## 🚀 Как Запустить

### Быстрый старт:
```bash
# 1. Клонировать репозиторий
git clone https://github.com/herman030103-eng/diebrowbar.git
cd diebrowbar

# 2. Настроить конфигурацию
cp .env.example .env
# Отредактировать .env

# 3. Запустить
./start.sh
```

### С Docker:
```bash
docker-compose up -d
```

### Ручная установка:
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python main.py
```

## 📋 Что Нужно для Запуска

1. **Python 3.10+**
2. **Email аккаунт** (Gmail/Yandex/Outlook)
   - Для Gmail: App Password
3. **OpenAI API ключ** или **Anthropic API ключ**
4. **Telegram бот**
   - Создать через @BotFather
   - Получить Chat ID через @userinfobot
